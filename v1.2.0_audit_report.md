## 2. Release Architecture & Scope Overview

### 2.1 The v1.1.0 to v1.2.0 Architectural Transition

Knox v1.1.0 provided an initial desktop prototype constructed using an immediate-mode GUI framework (`egui` and `eframe` version 0.32) coupled with native file dialogs (`rfd` version 0.17) in `src/gui/`. While functional for basic visualization, immediate-mode rendering placed severe constraints on responsive graph visualization, modern typography, component styling, and complex layout orchestration.

In Knox v1.2.0, the desktop presentation layer was completely transformed following the core architectural mandate:
> **"Rust owns the data. React owns the experience."**

#### Key Architectural Transformations:
1. **Total Excission of Legacy GUI (`src/gui/`)**:
   - The entire `src/gui/` directory tree (including `app.rs`, `canvas.rs`, `state.rs`, `theme.rs`, and all 8 sub-views) and its integration test (`tests/test_gui.rs`) have been permanently deleted from the codebase.
   - All references to `eframe = "0.32"`, `rfd = "0.17"`, and the CLI `gui` subcommand were completely excised from `Cargo.toml`, `src/lib.rs`, `src/main.rs`, and `src/cli/args.rs`.
2. **Introduction of the Tauri v2 Desktop Shell (`src-tauri/`)**:
   - Formed an independent workspace crate (`knox-desktop`) hosting the Tauri v2 application container.
   - Enforces the **Protected Core Rule**: `src-tauri/` contains **zero business logic** and **zero direct SQL statements**. It functions purely as an asynchronous IPC adapter delegating all state and domain computations to the public `knox` library crate (`knox::*`).
   - Implements native window management (frameless custom titlebar with drag region) and system tray lifecycle (window hide-to-tray upon closing).
3. **Delivery of the React 19 Frontend (`ui/`)**:
   - Built on React 19, TypeScript 5.7, Vite 6, and Tailwind CSS v4.
   - Utilizes `@xyflow/react` (v12) for interactive 60fps graph rendering with custom node cards, causal smooth-step edges, and four interchangeable layout algorithms (ELK Layered DAG, Dagre, D3 Physics Force, and Grid).
   - Houses a complete Linear/Raycast-inspired dark-mode design system utilizing OKLCH color tokens and bundled self-hosted fonts (`Inter` and `JetBrains Mono`).
